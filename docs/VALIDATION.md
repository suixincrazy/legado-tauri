## 当前构建

## 未入架书签与书架变更

全局书签列表包含未入架的记录，按书名、作者、章名和摘要搜索。点按未入架记录进入原文、摘要编辑，确认才保存；长按及删除沿用相同编辑器。全局 JSON / Markdown 导出完整范围，仍只输出原版八字段，搜索不会缩小导出范围。

单本移出或批量删除书架条目时保留书签，之后在全局页管理。导入或加入同名同作者书籍时自动关联；已有同一创建时间的在架记录优先，书名或作者不同的不会混合。只含书签的 Tauri 备份在原书籍标识不存在时，按备份中保留的书名和作者保存，之后再关联。字符位置、创建时排版及旧版比例位置均保留。旧书签仅有比例位置时无法生成原版精确字符位置。

相同书名、作者、创建时间的重复副本在全局页及导出中只出现一次；全局编辑和删除会在同一数据库事务内更新所有现存副本。单书阅读页的编辑仍作用于当前书籍。未入架高亮管理、缺少书名及作者的早期匿名书签备份、任意改名后的自动迁移尚未覆盖。

14 项新增回归覆盖未入架编辑、取消、删除、搜索与导出，书架单本和批量删除、再次入架、同名不同作者、重复版本、旧比例位置、仅书签备份在空书架恢复及排除选项、旧 ZIP 副本不复活已删除记录。浏览器在 390×844、834×1194、1194×834 验证列表和编辑器无横向溢出；通过实际界面编辑、取消、删除、搜索、JSON / Markdown 下载及移出书架验证。重新关联通过应用存储入口调用，之后通过界面确认书签可进入阅读页；重复版本的全局编辑和删除均核对持久数据。浏览器文件选择导入未在本版验收。

Android ARMv7 模拟器通过系统文件选择器恢复仅书签的公开 ZIP：预览 0 本书、3 条书签，恢复后均能在全局页显示。点按未入架条目打开编辑器，修改后取消并重开仍是原文；确认编辑后搜索显示一条，系统保存的 JSON 和 Markdown 仍包含全部三条。读回核对原版八字段、时间、字符位置、同名不同作者及分组均正确，取消内容未保存。系统选择器导入公开 EPUB 后，只有同名同作者的书签进入单书页，点按可进入正文；从详情移出书架后，书签仍保留并重新进入编辑器。删除另一作者的一条记录后再导出，剩余两条与之前导出逐字段一致。以上为本版 ARMv7 交互验收，不替代 ARM64/iOS 验收。

## 书签编辑、定位与导出

从阅读菜单添加书签会摘录当前可见正文；也可从选文创建。章名、原文、摘要分别保存，点确定才写入，取消不改书签。单书可搜索章名及摘要；全局列表按书名和作者分组。两处都支持编辑、删除及导出 JSON / Markdown，搜索仅过滤显示。新书签记录字符位置及创建时的标题、缩进设置；旧书签仅有比例位置的继续按比例跳转，无法补回其历史精确位置。

原版 ZIP 和 SQLite 中的字符位置、原文、摘要可带入书库。重新导出的 `bookmark.json` 保留这三项；只选择书签而不选择书架时也会生成原版格式的数据。仅含书签的原版 ZIP 按书名和作者匹配已有书籍，未匹配条目保留在备份中，后续恢复对应书籍时再关联。`26112703` 未在管理页显示未入架条目，`26112704` 的对应实现见上文。

公开样例覆盖 UTF-16 字符位置、隐藏标题／缩进、同名或同作者的不同书籍、取消、失败保存、搜索、选择性备份和实际 SQLite 转换。浏览器在 390×844、834×1194、1194×834 三个尺寸检查列表、编辑框无横向溢出。用真实 DOM 选文创建书签，取消编辑后检查库未变；修订后核对两种范围的 JSON、Markdown 导出内容，位置、换行和摘要均保留。滚动阅读的目标字符落在可视区顶部；菜单创建的原文与当时可见的 12 段文字相符。切到横屏双页、隐藏标题并改变缩进后，旧书签目标仍在可视区；第三页新增的选文书签可返回同页。

Android ARMv7 模拟器通过系统文件选择器恢复含 2 本书、2 条书签的公开 ZIP。全局列表、实际长按编辑、修改后取消并重开、确认保存原文和摘要、按字符位置跳转均通过。菜单新增先取消，单书列表仍只保留原条目；再次确认后新增摘录。单书搜索只显示一条时，导出仍包含该书全部两条书签。两种范围的 JSON 和 Markdown 均通过系统保存并读回核对：原版八字段、字符位置、时间、原文、摘要和按书分组一致，取消内容未保存。本版 ARM64/iOS 交互及 Android 原生选文手柄未验收。

跨页选择手柄、手势切换书签及原版全部分页行为仍未等价；以上公开样例不能代表所有版式和系统版本。

## 规则订阅管理与导入

`3.26112702` 的恢复预览独立统计规则订阅，支持仅含 `sourceSub.json` 的 ZIP 和旧版嵌入副本。书源管理的“书源订阅”进入独立列表，可以新增、编辑、删除、拖动排序及重新编号。同地址的已存条目按 ID 独立更新，未知类型和扩展字段保留。自动更新、间隔及静默标志可以保存，尚无订阅后台定时任务。

手动打开 HTTP(S) 订阅会按类型预览书源、RSS 规则源或替换规则 JSON；确认后才保存所选条目。RSS 按内容中的 `sourceUrl` 识别，保留规则原文；普通 RSS/Atom 可阅读，自定义 RSS 解析规则尚不执行。替换规则按安全整数 ID 比较，超出范围的 ID 不导入。自动识别类型、动态地址和带前置脚本的订阅不执行。

19 项新增公开回归覆盖无写入预览、同地址与 64 位 ID 编辑、排序、HTTP 错误、取消后迟到响应与分类型导入。浏览器在 390×844、834×1194、1194×834 下检查列表与编辑器均无横向溢出；验证新增、地址冲突、取消、按 ID 删除、键盘排序、三种类型确认导入和备份回读。

浏览器实际选择仅含 2 条订阅的公开 ZIP：预览显示 0 本书、0 个书源、2 条规则订阅和 0 条阅读记录，取消后订阅不变。Android ARMv7 通过系统文件选择器预览仅含 7 条订阅的 ZIP，确认后进入独立订阅页；新增、编辑、自动/静默设置、实际长按跨行排序、书源与替换规则导入、RSS 预览取消及二选一导入通过。

ARMv7 首次导出的 ZIP 含 8 条订阅；对照导出数据核实排序、24 小时间隔、未知字段、相邻 64 位 ID、所选书源、RSS 规则和替换样例。随后在编辑器修订新增条目的地址，该最后一次保存后的 ZIP 未再验收。本版 ARM64 APK 已构建并验签，ARM64 和 iOS 的本版交互均未验收。

## 多类型规则订阅备份

`3.26112701` 修复原版 `sourceSub.json` 导入时只保留书源类型、再导出时丢失其他规则订阅的问题。保留书源、RSS 规则源、替换规则、MD3 自动识别及未知类型的 ID、排序、时间和扩展字段；仅包含该文件的备份也可读取。恢复按 ID 合并，保留无关条目和同地址的不同订阅。

旧版备份或数据库仍保留原始 `sourceSub.json` 或 SQLite `ruleSubs` 表时，可补回此前未映射的订阅；已无原始副本的数据无法重建。升级后的主动删除会随备份保留，不从旧副本再次恢复。书源管理显示订阅名称、类型和更新时间，更新或删除按条目标识操作，保留原始元数据。

20 项新增测试覆盖 ZIP/JSON 往返、内容选择、恢复合并、旧数据库升级、字段校验与界面更新/删除；真实 SQLite 转换及旧 WebView 的 JSON 兼容路径验证相邻的 64 位规则 ID 再导出时仍是精确的整数。全量 215 项公开测试和真实 JVM 契约通过，1 项可选外部输入跳过，TypeScript/Vite 构建通过。该版本的非书源类型、动态链接及带前置脚本的订阅保留数据并标注尚不支持更新；自动调度、全部规则类型更新、编辑和排序交互仍未等价迁移。

浏览器在 390×844、834×1194 和 1194×834 下显示五种订阅类型，页面和列表行均无横向溢出。通过界面更新一条书源订阅、删除该条目并重新导出 ZIP，同地址的 RSS 规则订阅及其他类型保持不变。

Android ARMv7 模拟器从系统文件选择器恢复仅含 `sourceSub.json` 的公开 ZIP，再通过应用导出。7 条订阅的类型、顺序及全部原始字段一致，两个相邻的 64 位 ID 均按原数值导出；另通过书源订阅更新进入预览并导入一个公开书源。补充模拟器验收：ARMv7 更新后导出仅改变所选订阅的时间与导入数；ARM64 覆盖安装后在主用户环境使用隔离公开测试数据再次导出，订阅和书源与 ARMv7 一致。模拟器次用户环境无法加载 ARM64 原生库；iOS 交互尚未验收。
