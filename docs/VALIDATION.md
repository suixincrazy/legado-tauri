# 构建与兼容性验证

本页只记录可公开复现的产品行为、构建结果及兼容边界。自动化测试、模拟器验证和实际设备验证分别标注；编译成功不代表完整兼容上游。

## 当前构建

当前源码版本为 `legado_app_3.26112605`，[构建 45816673427](https://github.com/suixincrazy/legado-tauri/actions/runs/45816673427) 的自动验证、Android、iOS 和附件上传均成功。Release 保持草稿。以下产物检查及本批双 ARM Android 模拟器验证对应此版；iOS 交互仍待验收。

- Android 生成 `armeabi-v7a`、`arm64-v8a` 和测试用 `x86_64` APK，各包含对应 ABI；版本与签名连续性检查通过。
- iOS 生成 arm64 无签名 IPA 和 Xcode 工程，最低系统版本 iOS 15，支持 iPhone/iPad 设备族。设备安装需要有效签名。
- TypeScript/Vite 生产构建、公开自动化测试和真实 JVM 书源契约通过。本地 Android Kotlin 编译及 ARM64 Rust 检查通过。
- 仓库生成工程中的 18 项 AppIcon 与原版资源生成的图标逐字节一致，实际 IPA 的 iPad 图标与已核验图标一致。启动图标和静态 LaunchScreen 使用原版资源。

## 本地书恢复与快照更新

`3.26112605` 统一本地导入与 WebDAV 缺失文件恢复的 TXT 规则处理，保留原文、目录规则、书籍标识、阅读位置和书签；支持从旧版文本书架条目恢复实际 EPUB。超出新目录的章节与字符锚点归零到可用章节。

本地完整自动测试 182 项通过，真实 JVM 书源契约单独通过后合计 183 项公开测试通过；1 项可选外部输入测试跳过。TypeScript/Vite 生产构建通过。

- 修复恢复前快照未遵循密码设置的问题：优先使用当前备份密码，未设置时使用本次成功解密的密码；无密码的快照不导出 Cookie、登录状态和 WebDAV 密码。
- 读取原版备份中的进度同步、同步增强、本地书自动上传/恢复、保留数量及新备份检查设置；系统目录、设备名和自动执行状态由当前设备保留。
- 云端进度文件名按原版规则替换特殊字符并保留首尾空格，避免已有进度文件无法匹配；比较字符位置时排除其他章节的旧位置。
- 双 ARM Android 模拟器使用公开样例验证 TXT 与 EPUB 缺失文件下载：已停用但被该书指定的 TXT 规则仍生效，保留三章目录、原文、书籍标识、书签及第二章进度；无可用规则时保留类似标题的正文；旧 TXT 条目恢复为实际 EPUB 类型。
- ARMv7 加密备份经 WebDAV 上传、错误密码拒绝、正确密码预览与确认恢复通过。当前密码及本次输入密码生成的恢复前快照均由独立 PBKDF2/AES-GCM 实现解密核对；无密码快照不含 Cookie、登录状态和 WebDAV 密码。备份密码本身不导出。
- ARM64 覆盖升级、读取 ARMv7 加密备份、确认恢复和再次上传通过；独立解密后书架、正文、设置、规则、记录和源状态一致。ARM64 云端进度确认后跳至目标章节，双 ARM 退出上传的进度已从服务端读回核对。本地 TXT 原文件逐字节上传由 `26112604` ARM64 验证；增强同步和 iOS 交互仍待原生验收。

## 书源与阅读

- QuickJS 支持声明式规则和纯 JS 书源的搜索、发现、详情、目录、正文流程，网络、编码/解密及状态通过公开契约测试。Android JVM 桥验证真实 Jsoup、Hutool、JCA 调用；iOS 提供常用 Java API 兼容实现。
- 书源列表的筛选、多选、区间选择、拖动、滑选、分组、导入冲突预览及编辑由自动测试和界面验证覆盖。规则补全有 250 项官方 Kotlin 输出差分样例。
- 调试器支持五类输入、阶段与规则日志、响应查看、发现刷新和停止后的回调隔离。底层已发出的原生请求仍需等待返回。
- 二维码生成/图片解析、原生分享桥、取消流程与导入预览已实现并测试；相机和全部平台分享目标仍需原生验收。
- TXT/文字 EPUB、目录规则、书签、高亮、阅读记录、正文编辑、替换规则、朗读及横屏双页有公开样例验证。手机与平板尺寸分别检查布局。

完整功能域差异及尚未逐项验收的入口见 [审查矩阵](audit/COVERAGE.md)。图文 EPUB、漫画/音频专用阅读器、全部脚本 API、后台调度及完整设置语义仍未等价迁移。
