## 封面 WiFi 版本构建

`legado_app_3.26112804` 增加封面设置「仅 WiFi」，默认关闭。按固定官方调用范围，搜索、发现和换源结果在开启时只通过 WiFi 请求新的网络封面；书架及详情（含模糊背景）仍允许加载。固定 MD3 的详情策略不同，本版以官方为准。阅读记录目前仍为文本列表，未补其独立封面。原版搜索局部更新封面时绕过限制的特殊分支未复刻。

Android 查询系统 WiFi 连接状态，iOS 使用原生网络路径；返回前台及网络变化时刷新。受限网络下载在原生请求及重定向前复核连接，单图上限 4 MiB。已下载封面可在非 WiFi 时使用独立缓存（最多 64 张、32 MiB），缓存不进入书架备份；本地 data 图片不发请求。浏览器只接受明确的网络类型，在线状态或 effectiveType 网速不能证明 WiFi；未提供类型时阻止结果列表新网络封面。关闭开关及书架/详情保持原图片加载路径。原生封面下载尚未覆盖完整书源请求头/JavaScript/认证规则，缓存也不等同于原版 Glide。

开关支持 Tauri JSON/ZIP、原版配置及 SQLite 转换；排除设置或封面、忽略封面时保留相应现有配置。修复排除封面备份恢复时丢失现有 coverConfig 的问题。390 项公开测试通过（含真实 JVM 契约），1 项可选外部输入跳过；14 项新增回归覆盖网络类型、缓存、并发、迟到响应、前后台、列表与详情范围、开关和备份。生产构建通过。

## 书源与阅读

- QuickJS 支持声明式规则和纯 JS 书源的搜索、发现、详情、目录、正文流程，网络、编码/解密及状态通过公开契约测试。Android JVM 桥验证真实 Jsoup、Hutool、JCA 调用；iOS 提供常用 Java API 兼容实现。
- 书源列表的筛选、多选、区间选择、拖动、滑选、分组、导入冲突预览及编辑由自动测试和界面验证覆盖。规则补全有 250 项官方 Kotlin 输出差分样例。
- 调试器支持五类输入、阶段与规则日志、响应查看、发现刷新和停止后的回调隔离。底层已发出的原生请求仍需等待返回。
- 二维码生成/图片解析、原生分享桥、取消流程与导入预览已实现并测试；相机和全部平台分享目标仍需原生验收。
- TXT/文字 EPUB、目录规则、书签、高亮、阅读记录、正文编辑、替换规则、朗读及横屏双页有公开样例验证。手机与平板尺寸分别检查布局。

完整功能域差异及尚未逐项验收的入口见 [审查矩阵](audit/COVERAGE.md)。图文 EPUB、漫画/音频专用阅读器、全部脚本 API、后台调度及完整设置语义仍未等价迁移。
