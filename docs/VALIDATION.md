本页只记录可公开复现的产品行为、构建结果及兼容边界。自动化测试、模拟器验证和实际设备验证分别标注；编译成功不代表完整兼容上游。

## 当前构建

版本 `legado_app_3.26112603`，应用提交 `legado_app_3.26112603`。[构建 45769291666](https://github.com/suixincrazy/legado-tauri/actions/runs/45769291666) 的自动验证、Android、iOS 和附件上传均成功。Release 保持草稿。

- TypeScript/Vite 生产构建、公开自动化测试和真实 JVM 书源契约通过。本地 Android Kotlin 编译及 ARM64 Rust 检查通过。

## 书源与阅读

- QuickJS 支持声明式规则和纯 JS 书源的搜索、发现、详情、目录、正文流程，网络、编码/解密及状态通过公开契约测试。Android JVM 桥验证真实 Jsoup、Hutool、JCA 调用；iOS 提供常用 Java API 兼容实现。
- 书源列表的筛选、多选、区间选择、拖动、滑选、分组、导入冲突预览及编辑由自动测试和界面验证覆盖。规则补全有 250 项官方 Kotlin 输出差分样例。
- 调试器支持五类输入、阶段与规则日志、响应查看、发现刷新和停止后的回调隔离。底层已发出的原生请求仍需等待返回。
- 二维码生成/图片解析、原生分享桥、取消流程与导入预览已实现并测试；相机和全部平台分享目标仍需原生验收。
- TXT/文字 EPUB、目录规则、书签、高亮、阅读记录、正文编辑、替换规则、朗读及横屏双页有公开样例验证。手机与平板尺寸分别检查布局。

完整功能域差异及尚未逐项验收的入口见 [审查矩阵](audit/COVERAGE.md)。图文 EPUB、漫画/音频专用阅读器、全部脚本 API、后台调度及完整设置语义仍未等价迁移。
