## 功能范围

- TXT/文字 EPUB、书架、目录、书签、阅读记录和本地备份。
- 脚本书源、QuickJS 运行时、Android JVM 桥和独立 ARM 包。iOS 使用常用 Java API 兼容实现。
- 书源管理、动态登录表单、发现分类和独立网页登录窗口。第三方网站可用性须单独验证。
- 经典界面、原版图标和欢迎页迁移；入口和未等价部分见该提交的审查矩阵。
